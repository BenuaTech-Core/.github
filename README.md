# BenuaTech-Core · `.github`

Служебный репозиторий организации: то, что видно на странице [github.com/BenuaTech-Core](https://github.com/BenuaTech-Core).

```
profile/
├── README.md          # главная страница организации
└── assets/            # баннеры, логотип, графика проектов
```

## Как это устроено

- `profile/README.md` — публичная витрина: продукты, направления, принципы. GitHub показывает его на странице организации.
- `profile/assets/banner-dark.png` и `banner-light.png` — баннер под тёмную и светлую тему GitHub (переключение через `<picture>` и `prefers-color-scheme`).
- `profile/assets/logo.png` — знак для аватара организации (1024×1024).
- Исходники макета (HTML/CSS, из которых рендерятся PNG) лежат вне репозитория; правки текста — прямо в `README.md`.

## Правила

- Текст — по делу, без маркетингового шума.
- Любое утверждение о продукте должно подтверждаться репозиторием или релизом.
- Картинки — не тяжелее ~600 КБ; для скриншотов используем PNG, для фото — JPEG.

## Правки

Мелкие правки — pull request в `main`. Крупные изменения структуры страницы — сначала issue с макетом.
